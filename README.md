A simple addon that adds a fusion boosted nuclear Tusko at 250kt, the biggest nuke in the game. Priced at 250 mil to make it somewhat balanced and a 12 second fuse timer.
The weapon is limited to the Medusa (internal bay), Darkreach and Alkyon. Medium hangars and aircraft carriers must exist for this weapon to be deployed at all.

Addon made using NO-Blueprinter

Requirements:
BepinEx https://github.com/BepInEx/BepInEx/releases
Nikkorap's Blueprinter (goes into your BepinEx plugin folder) https://github.com/nikkorap/NOBlueprinter-Releases/releases/tag/2.0.1

You can also use NOMM to install BepinEx and Blueprinter more easily

Finally, place the .nopb file inside your BepinEx plugins folder and voila
